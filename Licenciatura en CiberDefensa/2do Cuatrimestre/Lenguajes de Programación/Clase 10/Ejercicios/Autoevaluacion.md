# Cuestionario PHP, HTML y Web (1-20)

------------------------------------------------------------------------

## Pregunta 1

**El contenido generado por PHP no puede incluir etiquetas HTML**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\
**Justificación:** PHP puede generar e incluir etiquetas HTML sin
problema.

------------------------------------------------------------------------

## Pregunta 2

**El lenguaje HTML admite comentarios**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Verdadero\
**Justificación:** HTML permite comentarios usando `<!-- -->`.

------------------------------------------------------------------------

## Pregunta 3

**JavaScript es un lenguaje de programación que se ejecuta en el
navegador del cliente**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Verdadero\
**Justificación:** JavaScript se ejecuta del lado del cliente en el
navegador.

------------------------------------------------------------------------

## Pregunta 4

**En la arquitectura cliente-servidor, el cliente solicita recursos y el
servidor responde.**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Verdadero\
**Justificación:** El cliente hace peticiones y el servidor responde.

------------------------------------------------------------------------

## Pregunta 5

**El servidor siempre envía código fuente PHP al navegador.**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\
**Justificación:** El servidor ejecuta PHP y envía solo el resultado
(HTML).

------------------------------------------------------------------------

## Pregunta 6

\*\*En PHP todas las variables comienzan con el signo
$.** **Opciones:** Verdadero / Falso **Respuesta correcta:** Verdadero **Justificación:** Todas las variables en PHP inician con `$\`.

------------------------------------------------------------------------

## Pregunta 7

**En un archivo .php, se puede incluir código HTML fuera de las
etiquetas PHP.**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Verdadero\
**Justificación:** Es posible mezclar HTML y PHP libremente.

------------------------------------------------------------------------

## Pregunta 8

**En un archivo .php se pueden mezclar bloques de HTML y bloques de

**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Verdadero\
**Justificación:** PHP permite código embebido en HTML.

## Pregunta 9

**Es obligatorio tener instalado Apache para ejecutar cualquier archivo
PHP en un servidor.**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\

## Pregunta 10

**Respuesta correcta:** Falso\

## Pregunta 11

**Respuesta correcta:** Falso\

## Pregunta 12

**JavaScript, HTML y CSS son lenguajes de programación del lado del

**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\
**Justificación:** Solo JavaScript es lenguaje de programación.

## Pregunta 13

**Las etiquetas HTML deben ir en mayúsculas para ser interpretadas**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\
**Justificación:** HTML es case‑insensitive, se usa minúsculas por
estándar.

------------------------------------------------------------------------

## Pregunta 14

**Los comentarios en PHP se escriben con `<!-- -->`**\
**Opciones:** Verdadero / Falso\
**Respuesta correcta:** Falso\
**Justificación:** Esa sintaxis es de HTML, PHP usa `//`, `#`, `/* */`.

## Pregunta 18
