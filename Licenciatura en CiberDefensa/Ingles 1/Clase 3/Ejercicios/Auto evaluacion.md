# Palabras transparentes (inglés → español)

## Listado principal:
- **Cybersecurity** → **Ciberseguridad**  
- **Digital** → **Digital**  
- **Era** → **Era**  
- **Individual** → **Individual**  
- **Information** → **Información**  
- **Attack** → **Ataque**  
- **Action** → **Acción**  
- **Data** → **Datos**  
- **Institution** → **Institución**  
- **Technology** → **Tecnología**  
- **Program** → **Programa**  
- **Education** → **Educación**  
- **Professional** → **Profesional**  
- **Seminar** → **Seminario**  
- **Conference** → **Conferencia**  
- **Collaboration** → **Colaboración**  
- **Government** → **Gobierno**  
- **Corporation** → **Corporación**  
- **Global** → **Global**  
- **Society** → **Sociedad**  
- **Strategy** → **Estrategia**  

## Términos adicionales:
- **Infrastructure** → **Infraestructura**  
- **Financial** → **Financiero**  
- **Personal** → **Personal**  
- **Corporate** → **Corporativo**  
- **Protocol** → **Protocolo**  
- **Policy** → **Política**  
- **Vulnerability** → **Vulnerabilidad**  
- **Audit** → **Auditoría**  
- **Incident** → **Incidente**  
- **Cooperation** → **Cooperación**  
- **Regulation** → **Regulación**  
- **Intelligence** → **Inteligencia**  
- **Reputation** → **Reputación**  
- **Credibility** → **Credibilidad**  
- **Market** → **Mercado**  

### Notas:
1. Algunos términos son préstamos directos (ej. `firewall`).  
2. Varios conservan raíz latina (ej. `collaboration` → `colaboración`).  
3. En contextos técnicos, muchos se usan en inglés (ej. `software`).
