# Línea de Tiempo de Historia de los Sistemas Operativos de los autores Andrew Tanenbaum y Jesús Torres
### Tarea realizada por Martín Alejandro Torres
## **1ª Generación**
- **1941**  
  - **Z3**: Primera computadora electromecánica programable (Konrad Zuse).  
- **1944**  
  - **Colossus**: Computadora electrónica para criptoanálisis (Reino Unido).  
- **1945**  
  - **ENIAC**: Primer ordenador electrónico digital de propósito general.  
  - **Z4**: Primer ordenador digital comercial (electromecánico).  
- **1953**  
  - **IBM 701**: Primer *mainframe* de IBM con tubos de vacío.  

## **2ª Generación**
- **1955**  
  - Primeros *monitores de sistema* (predecesores de los SO).  
- **1956**  
  - **GM-NAA I/O**: Primer sistema operativo (procesamiento por lotes).  
- **Años 1960**  
  - Lenguajes: **FORTRAN**, **COBOL**, **ensamblador**.  
  - Sistemas: **FMS** (Fortran Monitor System), **IBSYS** (IBM 7094).  

## **3ª Generación**
- **1964**  
  - **IBM System/360**: Familia de *mainframes* con circuitos integrados.  
  - **OS/360**: Primer SO multiprogramado (lanzado en 1966).  
- **1965**  
  - **MULTICS**: Primer SO de tiempo compartido (MIT/GE/Bell Labs).  
  - **VM/CMS**: Hipervisor para máquinas virtuales (IBM).  
- **1970**  
  - **UNIX**: Desarrollado por Ken Thompson y Dennis Ritchie (Bell Labs).  
  - **Lenguaje C**: Creado para reescribir UNIX (portabilidad).  
- **1974**  
  - **VMS**: SO para minicomputadoras VAX (DEC), con memoria virtual.  
- **1978**  
  - **BSD UNIX**: Variante de UNIX con TCP/IP (Universidad de Berkeley).  

## **4ª Generación**
- **1974**  
  - **CP/M**: Para microcomputadoras (Intel 8080/Z80).  
- **1980**  
  - **POSIX**: Estándar para compatibilidad entre sistemas UNIX-like.  
- **1981**  
  - **MS-DOS**: Microsoft para IBM PC.  
- **1984**  
  - **Macintosh System 1**: Primera GUI exitosa (Apple).  
- **1985**  
  - **Windows 1.0**: Extensión gráfica de MS-DOS.  
- **1987**  
  - **OS/2**: SO de IBM/Microsoft (modo dual protegido).  

## **5ª Generación**
- **1991**  
  - **Linux**: Núcleo de Torvalds + herramientas GNU.  
- **1993**  
  - **Windows NT**: SO de 32 bits (base de Windows actual).  
- **1995**  
  - **Windows 95**: Interfaz gráfica unificada.  
- **2000/2001**  
  - **Mac OS X**: Basado en BSD y núcleo Mach (Apple).  
- **2008**  
  - **Android**: SO móvil basado en Linux (Google).  
- **2015**  
  - **Windows 10**: Unificación de plataformas.
